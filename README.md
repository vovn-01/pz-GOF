# Реалізація GOF Патернів Проєктування на TypeScript

Цей проєкт демонструє використання 6 класичних патернів проєктування, вирішуючи архітектурні проблеми за допомогою мови TypeScript.

## Як запустити проєкт

1. Встановіть залежності: `npm install`
2. Запустіть демонстраційний сценарій: `npm start`

## Опис реалізованих патернів

### Породжувальні патерни (Creational)
1. **Builder (Будівельник)**
  * **Призначення:** Дозволяє створювати складні об'єкти покроково.
  * **Покращення:** Усуває проблему "телескопічного конструктора" з величезною кількістю параметрів. Дозволяє створювати різні конфігурації об'єкта одним і тим же кодом.
2. **Abstract Factory (Абстрактна фабрика)**
  * **Призначення:** Створює сімейства пов'язаних об'єктів (напр. UI компоненти Windows та macOS).
  * **Покращення:** Гарантує, що створені об'єкти будуть сумісні між собою, абстрагуючи клієнтський код від конкретних класів.

### Структурні патерни (Structural)
3. **Facade (Фасад)**
  * **Призначення:** Надає простий інтерфейс до складної підсистеми.
  * **Покращення:** Зменшує зв'язність (coupling) між клієнтом та складною системою, інкапсулюючи внутрішню логіку взаємодії безлічі класів.
4. **Proxy (Замісник)**
  * **Призначення:** Надає сурогатний об'єкт, який контролює доступ до оригінального об'єкта.
  * **Покращення:** Дозволяє винести логіку контролю доступу, лінивого завантаження чи кешування зі справжнього об'єкта (дотримуючись Single Responsibility Principle).

### Поведінкові патерни (Behavioral)
5. **State (Стан)**
  * **Призначення:** Дозволяє об'єкту змінювати свою поведінку під час зміни його внутрішнього стану.
  * **Покращення:** Позбавляє код гігантських умовних операторів (if/switch), які контролюють стан, розподіляючи логіку між класами станів.
6. **Command (Команда)**
  * **Призначення:** Інкапсулює запит як об'єкт, дозволяючи логувати запити, ставити їх у чергу або скасовувати.
  * **Покращення:** Відокремлює об'єкт, який ініціює операцію (Invoker), від об'єкта, який знає, як її виконати (Receiver). Дозволяє легко реалізувати функціонал Undo/Redo.
